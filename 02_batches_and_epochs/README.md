# Chapter 02: Batches and Epochs

Understand how batch size, example order, steps, and epochs change training.

## Start here

Open [01_lessons.ipynb](01_lessons.ipynb) and run its cells from top to bottom.
Run the local setup cell first; the notebook is self-contained.

## Lessons in order

1. Inspect one example at a time: batch size 1
2. Reverse example order with batch size 1
3. Train with mini-batches of two examples
4. Compare batch sizes after one epoch
5. Compare epochs, updates, and examples processed
